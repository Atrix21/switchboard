# Security

Switchboard moves keyboard input between computers, so security problems matter. Please report them privately through [GitHub's private vulnerability reporting](https://github.com/Atrix21/switchboard/security/advisories/new) rather than in a public issue.

What's in scope: anything that lets a device that hasn't been paired inject input, read input or clipboard contents, impersonate a paired computer, reach the service from outside the local network, or leave a user without local control of their mouse and keyboard.

How the protocol is meant to work is described in [ARCHITECTURE.md](ARCHITECTURE.md#security).
